# Code of Conduct

## Purpose

This project is a shared space for respectful collaboration. We welcome contributors of all backgrounds, experience levels, and identities.

We expect all interactions to stay professional, constructive, and focused on improving the project.

## Our standards

Contributors should:

- Be respectful in all discussions, reviews, and decisions.
- Assume positive intent and ask clarifying questions before judging.
- Give feedback that is specific, kind, and actionable.
- Accept feedback with openness and professionalism.
- Keep technical debates focused on facts, trade-offs, and outcomes.
- Help create a welcoming environment for new contributors.

Contributors must not:

- Harass, insult, or demean others.
- Use discriminatory, hateful, or sexualized language.
- Share private information without explicit permission.
- Intimidate, threaten, or target individuals in public or private channels.
- Disrupt collaboration through repeated bad-faith behavior.

## Scope

This Code of Conduct applies to all project spaces, including:

- GitHub issues, pull requests, reviews, and discussions.
- Repository documentation and code comments.
- Any direct communication related to project collaboration.

## Reporting concerns

If you experience or witness unacceptable behavior, report it privately and promptly.

- Use the process in [SECURITY.md](SECURITY.md) when relevant.
- If your concern is not security-related, contact repository maintainers directly through GitHub.
- Include links, screenshots, and timestamps when possible.

All reports are reviewed in good faith and handled as confidentially as possible.

## Enforcement

Maintainers are responsible for enforcing this Code of Conduct fairly and consistently.

Depending on severity and pattern, maintainers may:

- Ask for behavior to stop and provide guidance.
- Remove or edit violating comments, issues, or pull requests.
- Temporarily restrict participation.
- Permanently remove access from the project.

## Resolution principles

When handling reports, maintainers will:

- Prioritize community safety.
- Evaluate context and available evidence.
- Apply consequences proportionally.
- Document decisions for maintainers.

## Commitment

By participating in this project, you agree to follow this Code of Conduct and support a respectful, professional community.
