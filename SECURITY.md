# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the default branch.

| Version | Supported |
| ------- | --------- |
| main    | Yes       |
| older branches | No |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.

Report vulnerabilities by emailing: me@johnnolan.dev

Include the following details:

- A clear description of the issue
- Steps to reproduce
- Proof of concept or exploit details, if available
- Impact assessment
- Suggested remediation, if known

## What to Expect

- We will provide status updates as we validate and triage the report.
- We will coordinate a fix and disclosure timeline with you.

## Disclosure Policy

- Please allow us reasonable time to investigate and remediate before public disclosure.
- After a fix is available, we may publish a security advisory.

## Scope

This policy covers:

- Terraform configuration in this repository
- GitHub Actions workflows in this repository

This policy does not cover:

- Third-party services not controlled by this project
- Misconfiguration in downstream consumer environments
